# GK KA-Training

Lernseite für die GK-Klassenarbeit (Klasse 9, Baden-Württemberg): Gemeinde und ihre Organe, Politikzyklus, Partizipation, Medien in der Demokratie, digitale Medien und politische Willensbildung, Methoden und Operatoren.

Zu jedem Thema gibt es eine Erklärung, Videos, Aufgaben mit Musterlösungen, ein Quiz und interaktive Trainer. Dazu kommen ein Spickzettel und eine Probe-KA.

Reine HTML/CSS/JS-Seite ohne Build-Schritt: `index.html` im Browser öffnen oder über GitHub Pages veröffentlichen.
