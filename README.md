# NwT KA-Training

Lernseite für die NwT-Klassenarbeit (Klasse 9): Technisches Zeichnen, Hebel & Drehmoment, Getriebe, Schaltungen, Stabilität, Seifenblasen und Produktentwicklung.

Zu jedem Thema gibt es eine Erklärung, Videos, Aufgaben mit Lösungen, ein Quiz und interaktive Trainer. Dazu kommen eine Formelsammlung und eine Probe-KA.

Reine HTML/CSS/JS-Seite ohne Build-Schritt: `index.html` im Browser öffnen oder über GitHub Pages veröffentlichen.
